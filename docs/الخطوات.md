# تشغيل نظام إيميكو: الخطوات واحدة واحدة

> الوقت المتوقع: ساعة تقريباً، ومنعملها سوا.
> القاعدة الذهبية: أي مفتاح سري (service_role، sb_secret، VAPID_PRIVATE، CRON_SECRET، مفتاح الليرة اليوم، كلمة سر قاعدة البيانات) بينحط بإيدك بـ Secrets بس. ما بينكتب بالكود، ولا بالشات، ولا بيبيّن بلقطة شاشة.

## شو في بالملف
- `web/` الموقع والتطبيق (PWA). بينرفع على GitHub Pages.
- `supabase/schema.sql` قاعدة البيانات كاملة مع الصلاحيات (RLS) والعمليات. **خاص، ما بينرفع على ريبو عام.**
- `supabase/functions/` الدوال: سعر الصرف، إرسال الإشعارات، صباح الخير ومساء الخير والمهام المتكررة.
- `supabase/cron.sql` جدولة الدوال.
- `supabase/first-admin.sql` أول حساب مدير.
- `tests/e2e.py` اختبار النسخة التجريبية.

## قبل ما نبلّش: جرّب النسخة التجريبية
افتح `web/index.html` من خلال أي سيرفر بسيط، أو افتح رابط المعاينة اللي بعتتلك ياه. بتختار أي موظف وبتجرّب النظام بصلاحياته. البيانات وهمية وبترجع لحالتها كل يوم.

---

## 1) Supabase: المشروع
1. ادخل على supabase.com ← **New organization** ← اكتب `IMICO` ← خطة **Free** ← **Create organization**.
2. **New project**:
   - Name: `imico`
   - Database Password: اكبس **Generate a password** واحفظها عندك (مو بالشات).
   - Region: اختار أقرب منطقة (Frankfurt عادة).
   - **Create new project**، واستنى دقيقتين.

## 2) Supabase: قاعدة البيانات
1. من القائمة اليسار: **SQL Editor** ← **New query**.
2. الصق محتوى ملف `supabase/schema.sql` كاملاً ← **Run**.
3. لازم يطلع `Success. No rows returned`. إذا طلع خطأ، صوّرلي الرسالة.

## 3) Supabase: أول حساب مدير
1. **Authentication** ← **Users** ← **Add user** ← **Create new user**.
2. اكتب إيميل المدير وكلمة سر قوية (صاحب الحساب بيكتبها). فعّل **Auto Confirm User**.
3. انسخ الـ **UID** تبع المستخدم.
4. افتح `supabase/first-admin.sql`، حط الـ UID والإيميل مكانهن، والصقو بـ SQL Editor ← **Run**.

## 4) Supabase: إعدادات الدخول
1. **Authentication** ← **Sign In / Providers** ← **Email**: اطفي **Allow new users to sign up** (ما في تسجيل مفتوح، المدير بيعمل الحسابات).
2. **Authentication** ← **Policies / Password**: الحد الأدنى 10 أحرف، وفعّل رفض كلمات السر المسرّبة إذا متاح.
3. **Authentication** ← **URL Configuration**: Site URL = رابط الموقع الحقيقي بـ https.

## 5) Supabase: الدوال
لكل دالة (`exchange-rate`، `push-send`، `daily-jobs`):
1. **Edge Functions** ← **Deploy a new function** ← **Via Editor**.
2. **غيّر الاسم قبل Deploy** للاسم بالضبط (الاسم بيصير الرابط للأبد).
3. الصق محتوى `index.ts`، والصق محتوى `_shared/common.ts` بملف اسمو `_shared/common.ts` جوّا نفس الدالة (أو بدّل سطر الـ import بمحتواه).
4. بعد الرفع: افتح الدالة ← **Details** ← اطفي **Verify JWT**.

## 6) Supabase: الأسرار (إنت بتحطهن)
**Edge Functions** ← **Secrets** ← **Add new secret**:
| الاسم | القيمة |
|---|---|
| `CRON_SECRET` | نص عشوائي 40 حرف (منولّدو سوا) |
| `SPTODAY_API_KEY` | مفتاح الليرة اليوم **الجديد** (بعد إعادة التوليد) |
| `SPTODAY_URL` | رابط نقطة الأسعار من توثيق الليرة اليوم |
| `VAPID_PUBLIC` | المفتاح العام للإشعارات |
| `VAPID_PRIVATE` | المفتاح الخاص للإشعارات |
| `VAPID_SUBJECT` | `mailto:info@imico.net` |

مفاتيح VAPID منولّدها سوا بأداة على جهازك، والخاص بيروح على Secrets مباشرة.

## 7) Supabase: الجدولة
1. **Database** ← **Extensions**: فعّل `pg_cron` و `pg_net`.
2. **Project Settings** ← **Vault**: أضف `project_url` و `cron_secret` (نفس CRON_SECRET).
3. **SQL Editor**: الصق `supabase/cron.sql` ← **Run**.

## 8) ربط الموقع بـ Supabase
**Project Settings** ← **API Keys**: انسخ **Publishable key** (`sb_publishable_...`) و**Project URL**.
بملف `web/js/config.js`:
```js
mode: 'live',
supabaseUrl: 'https://xxxx.supabase.co',
supabaseKey: 'sb_publishable_...',
vapidPublicKey: '...'
```
هالمفتاح المنشور الوحيد المسموح بالكود.

## 9) GitHub Pages
1. GitHub ← **New repository** ← الاسم `imico-app` ← **Public** ← **Create**.
2. **Add file** ← **Upload files** ← ارفع محتوى مجلد `web/` بس (مو `supabase/`).
3. **Settings** ← **Pages** ← Source: **Deploy from a branch** ← Branch: `main` / `root` ← **Save**.
4. بعد دقيقة بيطلع الرابط. فعّل **Enforce HTTPS**.
5. (لاحقاً) الدومين الخاص: **Custom domain** ← وبتضيف سجل CNAME عند شركة الدومين.

## 10) التثبيت على الأجهزة
- **ويندوز / لابتوب:** افتح الرابط بـ Edge أو Chrome ← أيقونة «تثبيت التطبيق» بشريط العنوان.
- **آيفون:** Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** Chrome ← القائمة ← «تثبيت التطبيق».
- بعد التثبيت: الإعدادات ← «تفعيل الإشعارات» ← «إرسال إشعار تجريبي».

## 11) كل تحديث
- ارفع رقم النسخة بـ `index.html` (`app.css?v=` و `app.js?v=`) وبـ `sw.js` (`imico-shell-v`). بدونها المستخدم بيضل على النسخة القديمة.

## شو لازم تعرف (للأمانة)
- النسخة التجريبية مجرّبة كاملة. الربط الحقيقي مع Supabase (الدخول، الدوال، الإشعارات) **ما تجرّب بعد**، لأنو ما في مشروع لسا. منجرّبو سوا بعد الخطوة 8.
- ملف قاعدة البيانات تجرّب على Postgres 16 محلي، مع محاكاة لـ Supabase: الصلاحيات والعمليات اشتغلت صح.
- رفع صورة الوصل فعلياً للتخزين لسا ما انربط بالواجهة (الواجهة بتفحص النوع والحجم وبتسجّل إنو في وصل). منكمّلو بعد ربط Supabase.
- نقطة أسعار الليرة اليوم (الرابط وشكل الرد) لازم نشوفها من توثيقهن، ونظبط الدالة عليها.
